# Планировщик подготовки к экзаменам

Вы вводите экзамены (дата) и темы (сложность 1-5). Программа сама раскладывает темы по дням,
учитывая лимит часов в день, и показывает календарь нагрузки и диаграмму Ганта (вкладки справа). Если отстаёте — нажмите
«Перепланировать»: невыполненные темы переедут вперёд, а если не помещаются до экзамена — программа предупредит.

## Запуск
    python3 main.py

Нужен Python 3.9+ с tkinter (входит в стандартную установку). Данные хранятся в папке `data/` (CSV).

## Ввод даты
Полная дата: `ДД.ММ.ГГГГ`. Можно короче: `25` (ближайшее 25-е число) или `25.11` (ближайшее 25 ноября). Щелчок по полю даты
открывает календарь, где нужное число выбирается кликом. В пустых полях виден серый текст-подсказка, курсор стоит в его начале.

## Контрольные
Кроме экзамена можно добавить «Контрольную» (тип выбирается рядом с датой). У контрольной своя дата и свои темы; кнопка «Несколько…»
позволяет отметить сразу много тем из списка и дописать свои через запятую. День перед контрольной — 1 час повторения (перед экзаменом — 2).

## Выпадающие списки
Экзамен выбирается из списка обычных предметов (Математика, Физика, История, Python и др.), а после выбора экзамена
в списке тем появляются типовые темы этого предмета. Уже добавленные не повторяются. Можно и ввести своё название руками.
Список лежит в `planner/catalog.py`.

## Автоподбор сложности
В поле «Сложность» по умолчанию стоит «авто»: программа определяет сложность (1-5) по названию экзамена и темы
по словарю слов в `planner/estimator.py` (например, «Математика» — 4, «Введение…» — на 2 легче, «Теоремы» — на 1 тяжелее).
Можно выбрать число вручную или поменять сложность у готовой темы кнопкой под списком тем. Словарь легко пополнить.

## Правила плана
- Часов на тему = сложность. Лимит в день по умолчанию 4, на одну тему в день — не больше 2 (оба числа меняются внизу окна),
  поэтому большая тема растягивается на несколько дней по 1-2 часа.
- Сначала самые сложные темы ближайшего экзамена.
- За день до экзамена — только повторение (2 ч), до контрольной — 1 ч. В день экзамена и после ничего не планируется.

## Тесты
    python3 -m venv .venv && .venv/bin/pip install pytest && .venv/bin/pytest

## Структура
- `planner/` — логика: `models.py` (Exam, Topic, проверки), `scheduler.py` (Planner), `storage.py` (CSV), `calview.py` (календарь), `ganttview.py` (строки диаграммы), `estimator.py` (автосложность), `catalog.py` (предметы и темы для списков)
- `ui/app.py` — окно tkinter, `ui/gantt.py` — диаграмма на Canvas; `main.py` — запуск; `tests/` — тесты

## Скриншоты и демо
- `python3 demo.py calendar|gantt|dialog|error` открывает окно с примерными данными.
- `python3 screenshots.py` сам проходит сценарий и сохраняет скриншоты окна в `docs/screens` (macOS).
- `python3 code_screens.py` рисует и сохраняет скриншоты самого кода (с подсветкой) в `docs/screens`.
- `python3 examples/io_demo.py` печатает примеры ввода и вывода без окна.
