Скриншоты для презентации и отчёта делает сама программа:

    python3 screenshots.py     (из папки проекта, macOS)

Скрипт открывает окно с примерными данными, проходит сценарий и сохраняет кадры сюда:
01_calendar, 02_gantt, 03_dialog, s1_empty, s4_risk_calendar, s4_risk_gantt (PNG).
04_error.png (сообщение об ошибке) снят вручную: системное окно ошибки программа сама не фотографирует.
После съёмки пересоберите документы (см. docs/build/README.txt).
