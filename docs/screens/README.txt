Скриншоты для презентации и отчёта (PNG). Положите сюда файлы с ТОЧНО такими именами:

01_calendar.png  - python3 demo.py calendar   (окно целиком, вкладка «Календарь нагрузки»)
02_gantt.png     - python3 demo.py gantt      (окно целиком, вкладка «Диаграмма Ганта»)
03_dialog.png    - python3 demo.py dialog     (только окно «Несколько тем»)
04_error.png     - python3 demo.py error      (только окно с сообщением об ошибке)

Снимок окна на Mac: Cmd+Shift+4, затем пробел, затем клик по окну (сохраняется на рабочий стол).
После этого пересоберите документы (см. docs/build/README.txt).
